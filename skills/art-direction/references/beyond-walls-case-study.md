# 《高墙之外》案例：从电影气质到混合像素 2D 游戏

本案例只依据《高墙之外》公开开源版中可验证的项目文件整理。它用于解释方法来源，不要求后续项目复制监狱题材、配色或角色比例；原项目图片、用户材料和非公开开发文件均不打包进本 Skill。

## 审阅范围

主要材料限于公开仓库中的 README、页面入口、公开资产目录和游戏运行时代码。下面的结论是对这些公开材料的原创方法分析，不包含电影帧、演员肖像、源台词或私人开发截图。

可定位的技术事实：

- 主画布为 `1280 × 720`、16:9 横屏；
- CSS 使用 `image-rendering: pixelated/crisp-edges`，Canvas 多处关闭 `imageSmoothingEnabled`；
- 主要房间底图约 `1254 × 1254`，院子底图为 `1234 × 1275`；
- 角色具有上下左右方向与步行动画，常见帧时长约 `140–170ms`；
- 代表性画面长期使用黑褐、石灰、旧金、土黄和低饱和蓝灰；明亮金黄承担标题、提示、出口和希望的强调角色。

## 真正发生的转译

原电影的价值不在“写实胶片外观”本身，而在长期压抑与短暂希望的反差、封闭空间、磨损材质、等待的时间感，以及雨水/光线在关键时刻带来的释放。游戏没有把所有画面做成一种相同精度，而是按功能分层：

| 资产族 | 游戏中的表现 | 保留的电影功能 |
| --- | --- | --- |
| 菜单/高潮画面 | 黑色剪影、雨线、强烈暖金逆光、大片负空间 | 用单一强画面建立“压抑中出现自由”的承诺 |
| 可玩环境 | 俯视房间和院子、暗边、土石/木/金属材质、清楚的通道和家具 | 把封闭、秩序和监控变成玩家可走的空间 |
| 角色 | 头身比放大、轮廓简化、制服色块、四向动作 | 在移动端和复杂背景上保留身份与情绪可读性 |
| 剧情关键帧 | 高细节漫画/插画式构图、缓慢推拉、淡入淡出和颗粒 | 保留电影的近景、时间蒙太奇和情绪停顿 |
| UI/对话 | 黑褐底、旧金/石材边框、旧纸张面板、高亮操作色 | 用材料语言把现代网页控件包回世界，同时保持交互优先级 |
| 小游戏 | 收音机偏铜棕，管道偏暗绿，但共享暗底、旧金边和硬边 | 场景可变，系统身份不变 |

这说明《高墙之外》更准确的分类是 `hybrid_pixel`：可玩资产采用像素化/硬边规则，剧情帧允许更高细节的插画或照片感处理，再用共同调色、颗粒、材质和光线统一。把它称作严格逐像素系统会掩盖真实生产方式。

## 可复用视觉内核

从项目反推的内核可以写成：

> 用低饱和、磨损而封闭的土石世界承载漫长等待；只在希望、出口和关键反馈上释放暖金光与清晰轮廓，并按“可玩空间—可辨角色—电影关键帧”分配不同细节等级。

可验证支柱：

1. **压抑底色，金色希望**：常态低明度、低饱和；金色不是装饰，而是叙事/交互强调。
2. **材质讲时间**：石、铁、旧木、纸张都有磨损和污渍，但纹理不能盖住路径、角色和文字。
3. **功能分层的细节预算**：地图读空间，角色读身份，剧情帧读情绪；不要求三者同样精细。
4. **封闭构图与出口反差**：墙体、暗角和边框制造包围；门、光、雨或地平线制造突破。
5. **克制动作，关键时刻释放**：常态动画短而稳定，高潮通过雨、雷、淡入和镜头推拉提高动态。

反支柱：高饱和糖果色全局使用、柔化/双线性缩放、所有表面同等脏、剧情帧遮蔽操作状态、每个小游戏各自发明一套 UI。

## 工作流教训

### 1. 不要从“像素风”开始

先写情绪不变量和交互约束，再决定严格像素还是混合像素。该项目的成功点是把电影功能分配到地图、角色、剧情帧和 UI，而不是把电影截图统一降采样。

### 2. 先锁显示尺寸，再画大图

原项目部分角色母图尺寸很大，最终在 1280×720 画布中缩小显示。可复用流程应更早锁定实际角色高度、原生单元格和整数/非整数缩放政策，避免光晕、比例漂移和动画帧边界不一致。

### 3. 强调色必须语义化

旧金、浅金和亮黄同时承担世界材质、文字与触控按钮。后续项目应在调色板里区分“世界暖光”“可交互强调”“危险/成功”等语义，避免所有亮色争抢注意力。

### 4. 跨资产 proof 比单张海报重要

一张雨夜菜单可以很有电影感，但整体方向必须同时在院子、房间、角色、对话框和小游戏中成立。Pilot set 应把这些内容放进同一实际画幅检验。

### 5. 允许局部色相变化，保持结构不变

管道场景可以从土黄转暗绿，收音机可以转铜棕；只要明度层级、边缘硬度、框架语言、强调色角色和动作节奏保持一致，变化会增强场景功能而不是造成风格碎裂。
