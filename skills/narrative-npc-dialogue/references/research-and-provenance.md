# Research and provenance

Read this reference when a film-derived NPC is not established well enough by the local game files. The selected film version is the default source boundary; an underlying book, play, comic, earlier film, or remake is a separate continuity unless the user deliberately includes it.

## Keep variants separate

Name the selected continuity before researching: exact film and cut, dub/language if it materially affects voice, sequel state, the game's reinterpretation, and any deliberate blend. If the user has not specified one, prefer the film version already used by the game and call out consequential ambiguity.

Use a small fact ledger while working:

| Claim | Provenance | Confidence | Allowed use |
|---|---|---:|---|
| Explicit current game fact | `GAME` | high | Treat as canon unless the user overrides it |
| Explicit user addition or change | `USER` | high | Treat as canon for this request |
| Fact or repeated behavior from the selected film | `FILM` | high | Import only when it does not conflict with the game |
| Fact from an underlying or alternate source | `OTHER_SOURCE` | high | Exclude unless that continuity is explicitly in scope |
| Reliable commentary or catalog summary | `RESEARCH` | medium | Use for orientation; verify important details |
| Behavioral conclusion from repeated evidence | `INFERENCE` | medium | Use for voice, labeled when consequential |
| New connective material | `INVENTED` | n/a | Keep compatible and avoid presenting it as source fact |

Do not turn `INFERENCE` or `INVENTED` material into backstory unless the user approves it.

## Research efficiently

Research only gaps that could change the lines: social register, moral pressure, relationship, knowledge, chronology, recurring imagery, verbal rhythm, or a character's behavior under stress.

Prefer sources in this order:

1. The selected film itself when supplied or legally accessible, plus official studio, production, distributor, or game materials.
2. A legally available screenplay, transcript, subtitle file, commentary, or creator/actor interview for that film version.
3. Institutional catalogs and reputable scholarship.
4. Secondary summaries for discovery, followed by verification where the detail matters.

Search for scenes, choices, reactions, and relationship changes, not adjective lists. Collect paraphrased evidence such as “deflects risk with dry humor” or “answers authority with precise, formal wording.” Two or three independent behavioral examples from the selected film are stronger than a generic character profile.

If network access is unavailable, infer only from supplied material and label gaps. Do not block ordinary drafting merely because an exhaustive biography is unavailable.

## Convert evidence into a usable voice card

For each speaker, record:

- `public_mask`: how the character presents to this listener;
- `private_pressure`: what makes the present exchange difficult;
- `goal_now`: the result sought before the conversation ends;
- `power_and_trust`: relative authority, leverage, intimacy, and risk;
- `rhythm`: clipped, winding, hesitant, formal, interruptive, etc.;
- `lexicon`: work, faith, money, machinery, books, family, street language, and so on;
- `indirection`: jokes, questions, euphemism, silence, metaphor, threats, or over-explanation;
- `relationship_variants`: how the voice changes with authority, allies, rivals, strangers, and dependents;
- `conversation_moves`: habitual ways of opening, probing, evading, disagreeing, softening, joking, and leaving;
- `anti_voice`: speech patterns or degrees of candor that would sound wrong for the character;
- `knowledge_boundary`: direct knowledge, hearsay, suspicion, secret, and ignorance;
- `stress_shift`: how the voice changes under fear, anger, hope, or exposure.

The final line should be character-faithful because of these constraints, not because it copies recognizable phrasing.

## Adaptation and copyright boundaries

- Summarize source evidence; do not paste lengthy passages into working notes or output.
- Do not recreate a source scene beat-for-beat with synonyms.
- Do not write “in the exact style” of an author. Use character goals, behavioral traits, relationship dynamics, setting, and the game's own tonal guide.
- Attribute researched facts near the analysis when the user asks for sources. The generated dialogue itself should remain clean unless the game format calls for annotations.
- If source and adaptation disagree, either choose one or expose the difference. Never silently average them.

## Stop condition

Stop research when the selected canon, current relationship, knowledge boundary, voice contrast, and scene-specific pressure are supported well enough to draft. More biography is not automatically better dialogue.
